# 🚀 Strategický playbook pro web: programátor + hotové e-shopy pro mladé živnostníky

> **Referenční dokument pro stavbu webu v Claude Code.** Cílová skupina: mladí živnostníci 20–35 let, kteří rozjíždějí byznys nebo mají nefunkční web. Hlavní cíl: prodej programátorských služeb a hotových e-shopů/webů na českém trhu.

**TL;DR — 5 strategických závěrů:**
1. **Český trh konkurence je rozdělený mezi „lacinkáře" (Sales Web, Web za pár kaček, Webjo) a netransparentní agentury** — chybí designově silný brand pro 20–35 cílovku s fixní cenou a programátorskou hloubkou.
2. **Productized service model (DesignJoy, Flowout, ManyPixels) je v ČR téměř nezastoupen** = největší tržní mezera. Měsíční flat fee + pause/cancel anytime = magnet pro generaci 25–35.
3. **Demo-first model (BLEY) + transparentní fixní cena (DevBoys) + anti-vendor lock-in** = nejsilnější USP kombinace, kterou nikdo komplexně nedělá.
4. **Lead magnet stack pro CZ: kalkulačka ceny webu (TOFU) → audit report (MOFU) → 30min Calendly call (BOFU)**. SEO peak hledání: leden, září–říjen.
5. **Pricing pro CZ trh:** START 14 990 Kč / **BUSINESS 29 990 Kč ⭐** / PREMIUM 59 990 Kč + retainer 990/2 490/5 990 Kč/měs + alternativa „Web jako služba" 9 990 Kč/měs.

### 1.3 🕳️ MEZERA NA TRHU — co konkurence dělá špatně

1. **Lacinský brand** (Web za pár kaček, Sales Web) odpuzuje 25–35 cílovku, která chce „cool" image.
2. **Vendor lock-in** (NASTARTUJTO, Sales Web, Webjo, Digitální dílna) — netransparentně komunikováno.
3. **Subscription modely jsou v dlouhodobém horizontu dražší** než web na míru — konkurence to skrývá.
4. **Generické řemeslné cílení** (instalatér, truhlář) — chybí web pro **moderní oborové cílovky** (kavárny, fotografové, kouči, IT freelanceři, módní značky).
5. **Slabé reference** — křestní jména, generická hodnocení. Chybí case studies s metrikami v Kč/%.
6. **Většina webů sama nepůsobí moderně** — paradox: agentury staví web jako z 2018.
7. **Mlhavé ceny** (Anque, Pajskr) — Gen Z/Y nesnáší „kontaktujte nás pro cenu".
8. **Žádný designově silný brand** — všichni vypadají korporátně/laciné.
9. **Programátorská hloubka chybí** — většina je „WordPress + Elementor". Reálné integrace (Next.js, headless CMS, Fakturoid API) téměř neexistují.
10. **AI argumentace** — jen NASTARTUJTO ji aktivně používá.

5. **Klientská loga over-the-fold** — Jasper, Stripe, Google, Meta, Spotify…
6. **Single primary CTA** + 1 sekundární (typicky „Book a demo" / „See pricing").
7. **Founder-led trust signal** — DesignJoy: „run entirely by Brett" je prodejní výhoda.
8. **Award badges** (Awwwards, Webflow Agency of the Year, FWA) = autorita.

## 🎯 ZÁVĚR — proč tato strategie vyhraje

Český trh webdesignu pro živnostníky je rozdělen mezi **dvě extrémy**: lacinkáře s amatérským brandem (Sales Web, Web za pár kaček) a netransparentní agentury s ceníky „kontaktujte nás".
